A tiny stack VM for [make.fun's tiny-stack-vm-01 bounty](https://make.fun/bounty/tiny-stack-vm-01-run-20261122): 32-bit wrapping ints, 256-value stack, 64-deep call stack, 256 words of memory, ten traps. It writes `/output/<id>/stdout.bin` and `/output/<id>/exit.txt` per program.

Run with `node main.ts` (Node 22, no dependencies). `MAKEFUN_INPUT_DIR` / `MAKEFUN_OUTPUT_DIR` override `/input` / `/output`.
